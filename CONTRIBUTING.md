# Contribution

You can contribute to this repository in multiple way:

- Fix some typo
- Add new exercises, theme
- Request some changes or precision in exercises

## How to contribute

To contribute to this repo you can simply:
clone the repository

```bash
git clone https://github.com/RoiShigaiOrg/Embedded_Exercises.git Robotic_Club_exercises && cd Robotic_Club_exercises
```
open another branch where you will add your content

```bash
git checkout -b <Feature Name>
```
After adding your exercises, update your branch with the distance repo

```bash
git pull origin main
```
*Git add, git commit... etc*

Push to the distant repository and open a PullRequest

```bash
git push origin <Feature Name>
```

## External Contribution

If you are not a members of the Robotic Club of our campus, please let us now in Pull Request your status, if you are a professional in the industry or an hobbyist and explain how you found/learned about this repository.
PR evaluation

Each PR must be evaluated by one or two members of the Club, depending on the active member. Discussion can be openend about the relevantness of your PR and we can refuse to merge/close this PR depending of the nature of the PR.
